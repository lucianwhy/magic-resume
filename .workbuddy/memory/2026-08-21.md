## 用户提问：CRUD 全链路与数据库技术栈

用户询问项目用的什么数据库、涉及建表存数据的文件在哪。已完整梳理并讲解：

- **数据库是 PostgreSQL 16**（不是 MySQL），通过 `docker-compose.yml` 启动容器，端口 5432，库名 `magic_resume`
- 驱动是 `psycopg`（纯 Python），ORM 是 `SQLAlchemy 2.0`，迁移工具是 `Alembic`
- 真正执行 `CREATE TABLE` 的文件：`services/api/alembic/versions/20260810_01_create_users_and_profiles.py`
- ORM 模型：`app/models.py`（Base + User）、`app/modules/profile/models.py`（Profile）
- 数据库连接：`app/core/database.py`（engine + SessionLocal + get_db）、`app/core/config.py`（从 .env 读 DATABASE_URL）
- CRUD 四层：`repository.py`（db.get/db.add）→ `service.py`（db.commit）→ `router.py`（HTTP）→ `schemas.py`（DTO）
- 前端入口：`apps/web/src/features/profile/api.ts`（fetchProfile / updateProfile）
- 以后做 projects CRUD 时，需新建 `app/modules/projects/` 五件套 + Alembic 迁移脚本
