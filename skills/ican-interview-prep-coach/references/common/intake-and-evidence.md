# 输入、证据与训练记录

## 输入优先级

1. 用户明确陈述和可打开的项目证据。
2. 个人职业知识库中的确认事实与开放问题。
3. 当前目标 JD。
4. 当前定制简历。
5. 本 Skill 的通用知识与建议。

## 四类标签

| 标签 | 用法 |
| --- | --- |
| 已证实 | 有用户陈述、代码、截图、链接或知识库记录；可用于私下训练。 |
| 待核验 | 用户提过但缺统计口径、代码、职责边界或时间；可训练回答，但提醒补证。 |
| 未知 | 资料没有说明；提一个高价值问题，不做负面推断。 |
| 培训建议 | 推荐学习或架构方案；绝不改写成用户已经做过。 |

## 能力等级

不要从简历关键词推断熟练度。按主题判断：

1. 能解释概念。
2. 能在已有项目实现基本功能。
3. 能独立设计模块、接口和数据流。
4. 能定位故障、做取舍、说明降级。
5. 能在性能、成本、可靠性、观测约束下落地。

## 每次培训输出

- 目标：该阶段要解决的具体面试风险。
- 能力地图：已证实/待核验/未知/建议。
- 培训内容：概念或项目表达，必须联系 JD。
- 行动：一个可以在 30–90 分钟内完成的练习或补证。
- 知识库候选：仅列出用户新确认的原子事实，不直接写入。

## 不做的事

- 默认不进入计时问答、打断式追问或评分式模拟。
- 不虚构模型 API、向量库、并发指标、用户数据、任职时长或项目职责。
- 不把“理论上可以”说成“项目中已经做过”。
