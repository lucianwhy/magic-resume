# 可选的视频学习与字幕讨论

## 触发与边界

默认不得主动搜索视频、获取字幕或分析推荐视频。只告知用户：可以按当前能力缺口推荐 B 站视频，也可以读取用户指定的公开视频字幕后讨论。只有用户明确请求或回答“需要”后，才执行相应功能。

术语或缩写有歧义时先确认含义，例如 `IG` 不能自动等同于 RAG、AIGC 或 Agent。

B 站全站搜索使用网页内部接口，不是开放平台承诺稳定性的正式搜索 API。默认不使用 Cookie、`SESSDATA`、WBI 绕过或验证码规避。出现 `412`、HTML 验证页、超时或结构变化时立即停止 API 请求，保留已成功结果，并降级为普通 B 站搜索链接。

## 学习槽位

| 槽位 | 时长 | 目的 |
| --- | --- | --- |
| `quick_intro` | ≤10 分钟 | 建立概念直觉和术语边界。 |
| `architecture` | 10–30 分钟 | 理解完整链路、组件和数据流。 |
| `hands_on` | 30–180 分钟 | 跟随代码或项目完成一次实现。 |
| `interview` | 2–30 分钟 | 熟悉高频追问和表达结构。 |
| `evaluation` | 10–120 分钟 | 学习评估、排障和优化。 |
| `full_course` | >180 分钟 | 长期系统学习；面试前只按章节使用。 |

默认至少提供短科普、架构、实战和面试专项；评估优化按岗位要求加入；超长课程单列，不要求临时从头观看。

## 搜索流程

1. 确认用户已经要求视频推荐。
2. 根据当前概念、JD、项目和能力缺口生成最多四组查询：
   - `<主题> 科普 原理`
   - `<主题> 架构 工作机制`
   - `<主题> 项目 实战`
   - `<主题> 面试 评估 优化`
3. 运行：

```powershell
python scripts/search_bilibili_videos.py --topic RAG --angle all
```

4. 按 `bvid` 去重，过滤标题/简介/标签与主题无关的结果。
5. 从不同槽位各选 1–2 条；不要把搜索排序或播放量当作质量结论。
6. 推荐前检查 URL、标题、UP 主、时长、发布日期和基础互动数据。不得为了核验推荐而自动抓取字幕。只有用户另行要求读取字幕，且实际检查字幕、章节或内容后，才可声称内容本身准确或完整。

## 读取字幕

用户提供公开视频链接并明确要求读取字幕时，调用 `$cheat-video2srt`。不要因为“刚推荐了视频”就自动转写。AI ASR 结果必须标注可能存在人名、产品名和英文术语误识别，不能冒充作者逐字原话。

执行前只检查环境变量是否存在，不显示值。按字幕 Skill 的路由使用：

- `TIKHUB_API_KEY`：TikHub 用户中心创建。主页 `https://www.tikhub.io`，文档 `https://docs.tikhub.io`；中国大陆 API 域名使用 `https://api.tikhub.dev`。
- `APIFY_TOKEN`：Apify Console 的 API & Integrations 页面创建：`https://console.apify.com/settings/integrations`。
- `VOLCENGINE_ASR_API_KEY`：火山引擎语音技术控制台创建应用并获取 APP ID/Access Token：`https://console.volcengine.com/speech/app`；参考官方语音文档 `https://www.volcengine.com/docs/6561`。

缺少凭据时：说明缺少哪个环境变量、它负责哪条降级链路、是否可能产生费用，并给出上述官方地址。引导用户在 Windows 用户环境变量中配置；不得要求用户把 Token 发到聊天中，不得写入 Skill、仓库、日志或命令 URL。用户配置后，新启动的 Agent 才会自动继承；当前进程未继承时可以安全读取用户级环境变量，但不得回显。

## 筛选标准

优先考虑：主题相关度、当前能力缺口、岗位/项目匹配、简介与章节具体度、时长适配、配套代码或原始资料。播放、收藏、投币只作弱信号。

降低优先级或提示风险：

- “通过率 98%”“唯一最全”“少走 99% 弯路”等营销标题。
- 简介主要引导私域或领取资料。
- 标题年份晚于实际发布日期。
- 没有有效 `bvid`、无法核验、范围与搜索词不符。
- 超长合集没有可定位章节。

## 推荐卡片

每条输出：标题与链接、UP 主、时长、发布日期、适合槽位、为什么适合当前用户、重点看什么、看完应能回答的问题、内容/时效风险。明确标注“API 元数据初筛”或“内容已核验”。

## 看后闭环

用户选择观看或读取字幕后，才要求其用自己的话输出：一句话定义、最小架构、一个常见坑、与自己项目的映射、仍不理解处。再更新能力等级；用户确认后，才能将新的掌握状态或项目事实回写职业知识库。
