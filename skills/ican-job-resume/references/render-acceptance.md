# 导出验收规则

目标：同一简历版本在工作台预览、PNG 和 PDF 中内容一致、页面完整、页数符合要求。

必须记录：

- `resume_id` 与输入 JSON 的 SHA-256。
- 渲染器名称和版本。
- 网页截图、PNG、PDF 的绝对路径。
- PDF 实际页数、每页尺寸、生成时间。
- 可读文本摘要或文本哈希。

失败条件：

- PNG/PDF 出现左右裁切、空白半页、缩放错位或缺失头像。
- PDF 页数超过约束。
- 预览、PNG、PDF 的输入版本不同，或文本摘要明显不一致。
- 使用与工作台不同的手写 HTML 模板作为交付渲染器。

分页规则：以真实 A4 PDF 边界为准；允许跨页，但不得把章节标题留在页底、不得把一个不可拆分条目错误截断。页面超限时先减少重复表述，再要求用户确认可删内容。
