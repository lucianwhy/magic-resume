# JD 分类

将 JD 分为以下字段，避免把所有关键词当硬要求：

| 字段 | 定义 | 简历处理 |
| --- | --- | --- |
| `must_have` | 明确要求、任职资格、硬门槛 | 有证据则前置；无证据标缺口 |
| `preferred` | 优先、加分、熟悉更佳 | 有证据才写 |
| `responsibilities` | 入职后职责 | 映射相近已完成工作，不承诺未做过职责 |
| `domain` | 行业、用户、业务语境 | 调整项目叙事顺序 |
| `constraints` | 城市、学历、年限、出勤等 | 如实呈现，不能包装规避 |
| `keywords` | ATS/招聘者检索词 | 仅在真实语境中使用 |

输出项必须使用 `supported`、`partial`、`needs_confirmation` 或 `unsupported`。关键词缺失不等于用户不会该项。
