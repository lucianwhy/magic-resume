# 初始化后路由

| 状态 | 唯一优先动作 |
| --- | --- |
| 用户有简历或已有资料，但尚未导入 | 提示提供材料，调用 `$ican-career-knowledge-base` 导入和核验 |
| 用户没有简历 | 调用 `$ican-career-knowledge-base` 分步建立基础职业档案 |
| 已有事实库，没有目标岗位 | 引导用户给出目标岗位或简历方向 |
| 已有事实库和 JD，需要简历 | 调用 `$ican-job-resume` 创建不覆盖原件的定制版本 |
| 已有事实库、JD 和候选简历 | 调用 `$ican-interview-prep-coach` 进行对应轮次的面试前培训 |
| 工作区结构损坏或版本不明 | 运行 doctor；只修复结构，不推测业务事实 |

## 输出模板

初始化结束只给一个推荐动作：

```text
工作区：<绝对路径>
状态：<已创建 / 已识别 / 已修复>
已有资料：<简历、知识库、JD 的状态>
下一步：<一个动作>
你可以直接说：<一条可复制的用户指令>
```

不要一次让用户在三个业务 Skill 之间自行选择。
