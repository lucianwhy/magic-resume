# 开始使用 ICAN

ICAN 帮助你长期整理职业事实，并围绕具体岗位生成定制简历和面试前培训。

## 第一次使用

如果已有简历，可以直接说：

> 导入这份简历，建立我的职业知识库。

如果没有简历，可以直接说：

> 我没有简历，请从零开始帮我建立职业档案。

如果已有目标岗位，可以同时提供岗位 JD；没有也不影响开始。

## 常用指令

- “补充这段项目经历到我的职业知识库。”
- “根据这份 JD 创建一份不覆盖原件的新简历。”
- “按照技术面对我做面试前培训。”
- “检查我的 ICAN 工作区还缺什么。”

AI 客户端入口：Codex 使用 `AGENTS.md`，Claude Code 使用 `CLAUDE.md`。两者共享 `.ican/AI_CONTEXT.md`。
